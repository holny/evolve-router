EvolveRouter — 路由公式

每一项都对应具名量。飞轮与探索只能微调——决策模型的判定是不可逾越的天花板。

0 · 价格感知四层 难度 → 档位 → 硬闸 → 缓存/经济学（2026-10）

$$d_{\mathrm{eff}} = \mathrm{calib}(d_{\mathrm{raw}})\;\xrightarrow{\;\text{滚动分位重塑（70/20/10）}\,}\;\text{L1}|\text{L2}|\text{L3}$$ $$\text{档位上限} = \begin{cases} \text{cheap} & d_{\mathrm{eff}} \le 0.8\\ \text{cheap}|\text{medium} & d_{\mathrm{eff}} \le 2.0\\ \text{全开} & \text{其他}\end{cases}\qquad \text{硬闸：}\ \text{档位}(m) \le \text{上限} \ \lor\ \text{成本}(m) \le \operatorname{中位}_{\text{同家族允许层}} \text{成本}$$ $$\text{有效成本}(m) = \Big(\big[\,p^{\mathrm{未命中}}_{\mathrm{入}}(1-h) + p^{\mathrm{命中}}_{\mathrm{入}} h\,\big]\cdot T_{\mathrm{入}} + p_{\mathrm{出}} T_{\mathrm{出}}\Big) \times \text{峰谷}(t) \qquad \text{暖缓存不被替换，除非对手便宜 } >15\%$$
$d_{\mathrm{eff}}$ 经滚动分位校准（目标 70% 简单 / 20% 一般 / 10% 困难）。能力档与价位档按分位分配，且只在当前可用池上统计（冷却 / 配额闸门 / 无凭据的模型动态排除）。比例控制器再把实际选用的档位占比拉回 7:2:1。峰谷与缓存命中价来自 provider 注册表；活跃集 50 席只保留最近发布（保底 20 席）+ 最近使用（14 天内）的模型。

1 · 综合评分

$$\text{score}(m) = \underbrace{\Big[\textstyle\sum_k W_k \cdot f_k(m)\Big]}_{\text{five factors}} \times \underbrace{B(m)}_{\text{flywheel bias}} \times \underbrace{P(m)}_{\text{budget damp}} \times \underbrace{\big(1 + 0.15\,c_r\big)}_{\text{advisor bonus}}$$
Q quality+ S speed+ C cost+ R reliability+ H headroom

2 · 动态权重 难度联动 × 配额感知（BaRP Eq.1）

$$\mathbf{W} = \operatorname{norm}\Big(\underbrace{\mathbf{w}^{\,\mathrm{diff}}(d_{\mathrm{eff}})}_{\text{难任务}\,\Rightarrow\,\text{质量}\uparrow} \odot \underbrace{\mathbf{w}^{\,\mathrm{quota}}(t)}_{\text{配额紧}\,\Rightarrow\,W_c(1+1.5t),\,W_q(1-0.25t)}\Big), \quad t \in [0,1]$$
t = 剩余配额不足 8× 预估 token 的候选占比；无配额数据时不干预。质量下限随难度单调上行：d≈0 时 0.50 → d=3 时 0.85——简单任务由成本决定，困难任务必须有实力。

3 · Thompson 探索 BayesianRouter Eqs.4–6 — 不确定性驱动，自动收敛

$$\mu_0 = 0.15 + 0.70\,\mathrm{rank}(q), \qquad \alpha = \mu_0\nu_0 + s, \quad \beta = (1-\mu_0)\nu_0 + f, \quad \nu_0 = 8$$ $$\tilde{\theta} \sim \mathrm{Beta}(\alpha, \beta), \qquad \text{score} \times \Big(1 + \rho\,3\,(\tilde{\theta} - \mathbb{E}[\theta])\Big), \qquad \rho = \texttt{explore\_ratio}$$
后验宽（样本少）→ 偏移大 → 自动多探索；后验窄 → 自动收敛。μ₀ 取 Jev 质量因子在候选集内的 相对位次（绝对 q 普遍贴顶 1.0，直接作先验会让探索系统性死亡）。

4 · 飞轮学习偏置 两阶段归一化（BayesianRouter App.B）+ 基线相对更新（BaRP Eq.6）

$$\operatorname{norm}(v) = \operatorname{clamp}\!\left(\frac{v - \bar{x}}{q_{80} - q_{20}},\ 0,\ 1\right) \qquad \mathrm{reward} = w_{\mathrm{ok}}\cdot\operatorname{norm}(\mathrm{ok}) + (1{-}w_{\mathrm{ok}})\cdot\big(1 - \operatorname{norm}(\ln t)\big)$$ $$B(m) = \operatorname{clamp}\Big(1 + \big(\mathrm{reward}(m) - \operatorname*{median}_{m'}\mathrm{reward}(m')\big)\cdot\gamma,\ 0.7,\ 1.3\Big)$$
两阶段：先减滚动均值，再按 20/80 分位距缩放。基线相对更新：飞轮学的是相对跨模型中位数的优势， 而非绝对结果——工作负载漂移不会泄漏进 bias。飞轮只能微调：|bias| ≤ 1.3。

5 · 决策管线

摘要信号→ 粘性检查（+ 暖缓存保留）→ 双判官（槽位链 JEV > LAYA > OPENAI + 启发式）→ 难度校准（7:2:1）→ 直推 advisor top-8（匿名画像）→ 硬过滤（上下文/视觉/健康/配额闸门/活跃集 50/价位层）→ 动态权重 × 比例控制器档位乘子→ 评分（有效成本：缓存命中 × 峰谷）→ Thompson 探索→ 路由 + 降级链(3) + 质量级联→ 结果 → 飞轮（+ 比例观测）
判定器/advisor/蒸馏/级联任何一处失败都不阻塞路由。学习只来自被选模型的 bandit 反馈。
